# PDF漫画ビューアー

PDFで出力された漫画を、macOS上で1ページ表示または見開き表示して読むためのビューアーです。右綴じ・左綴じの切り替え、見開き位置の調整、横長ページの単独表示、ページ単位の表示設定に対応しています。

## 必要環境

- macOS 15.0以降
- Swift 6.0以降（ソースからテスト・ビルドする場合）

## テスト

リポジトリのルートで次を実行します。

```sh
swift test
```

## アプリのビルドと起動

次のスクリプトでReleaseビルドのアプリバンドルを生成します。

```sh
scripts/build-app.sh
```

生成先は`build/PDFComicViewer.app`です。Finderでダブルクリックするか、次のコマンドで開きます。

```sh
open build/PDFComicViewer.app
```

この方法で生成したアプリはコード署名・公証を行っていないローカルビルドです。他のMacへ配布する場合は、別途コード署名と公証が必要です。

## 基本操作

- PDFを開く: ツールバーの「PDFを開く」、ファイルのドラッグ＆ドロップ、または `Command + O`
- 次へ進む: `Space`。矢印キーと画面左右のクリック領域は綴じ方向に応じて反転
- 前へ戻る: `Shift + Space`
- 1ページ表示: `1`
- 見開き表示: `2`
- 見開き位置を1ページずらす: `S`
- 拡大: `Command + +`
- 縮小: `Command + -`
- ウインドウに合わせる: `Command + 0`
- 全画面表示の切り替え: `Control + Command + F`

綴じ方向、表示方法、見開き位置、拡大・縮小、全画面表示はツールバーからも操作できます。見開き表示中にページ上で右クリックすると、そのページを「自動」「単独」「見開き」のいずれで扱うか指定できます。
