# PDF漫画ビューアー

PDF漫画をmacOSで1ページ表示・見開き表示して読むためのネイティブビューアーです。

## 主な特徴

- 右綴じ・左綴じ
- 1ページ・見開き表示の即時切り替え
- 横長ページの自動単独表示
- PDFごとのページ位置・表示設定の保存
- キーボード、クリック、ドラッグによる操作
- 左側のディレクトリサイドバーからPDFを選んで開く（開閉可能）
- シークバーによるページ移動、読書位置のリセット、PDFのゴミ箱移動
- シリーズ最後のページで自動的に次の巻を開く（1ページ目から手前の巻へも戻れる／オフにも切り替え可能）、サイドバーの絞り込み検索

## 必要環境

- macOS 15.0以降
- Swift 6.0以降（インストール・更新・ソースからのテスト・ビルドに必要）

## インストール

リポジトリのルートで次を実行します。このコマンドはReleaseビルドを行ってからアプリを配置します。

```sh
scripts/install-app.sh
```

`~/Applications/PDF漫画ビューアー.app` にインストールされ、自動的に起動します。

このアプリは未署名・未公証の個人利用向けローカルビルドです。ほかのMacへの配布には、別途コード署名と公証が必要です。

## 更新

ソースを更新した後、インストール時と同じコマンドを実行します。

```sh
scripts/install-app.sh
```

## 基本操作

- PDFを開く: ツールバーの「PDFを開く」、ファイルのドラッグ＆ドロップ、または `Command + O`
- 次へ進む: `Space`。矢印キーと画面左右のクリック領域は綴じ方向に応じて反転。最後のページで次へ進むと、同じフォルダに次のPDFがあれば自動的に開きます
- 前へ戻る: `Shift + Space`。1ページ目で前へ戻ると、同じフォルダに手前のPDFがあればその最終ページを開きます
- 1ページ表示: `1`
- 見開き表示: `2`
- 見開き位置を1ページずらす: `S`
- いま見ているページから先をずらす: `Shift + S`
- 拡大: `Command + +`
- 縮小: `Command + -`
- ウインドウに合わせる: `Command + 0`
- 全画面表示の切り替え: `Control + Command + F`
- PDFを閉じる: ツールバーの「PDFを閉じる」、またはFileメニューの「PDFを閉じる」
- ディレクトリサイドバーの表示切り替え: ツールバーまたはサイドバー左上のボタン、または `Command + B`
- ページを大きく飛ばす: 本文の下端にマウスカーソルを近づけるとシークバーが現れます
- 最初に戻る: ツールバーの「最初に戻る」、またはサイドバーで右クリックして「最初に戻る」
- PDFを削除する: ツールバーのゴミ箱ボタン、またはサイドバーで右クリックして「ゴミ箱に入れる」
- PDFを絞り込む: サイドバーの検索欄にファイル名やフォルダ名の一部を入力
- ディレクトリ一覧を再読み込み: サイドバーヘッダーの回転矢印ボタン、または `Command + R`

綴じ方向、表示方法、見開き位置、いま見ているページから先のずらし、隣の巻への移動、拡大・縮小、全画面表示はツールバーからも操作できます。見開き表示中にページ上で右クリックすると、そのページを「自動」「単独」「見開き」のいずれで扱うか指定できます。見開き位置のずらしは、最初に見開きにできるページを起点に切り替わります（表紙が横長ページのPDFでは、その次のページからずれます）。横長ページと「単独」指定のページは見開きの区切りになるため、それより後ろの組み合わせは `S` では変わりません。そこを読んでいる最中にずらしたいときは `Shift + S` を使います。こちらはいま見ている見開きの組み合わせを1ページ分ずらします（もう一度押すと元に戻ります）。見ているページはそのまま残り、隣に並ぶページが入れ替わります。なお、起点のページに組む相手がいない場合（次のページが横長、または「単独」指定になっている場合）は、`S` を押しても組み合わせが変わりようがないため、ツールバーのボタンが無効になります。ツールバーの各ボタンにマウスカーソルを乗せると、対応するキーボードショートカットがツールチップで表示されます。

ウインドウ左側のディレクトリサイドバーには、開いているPDFの親フォルダ以下がツリー表示されます。PDFをダブルクリックすると開き、フォルダの三角マークで展開・折りたたみができます（`Option` キーを押しながらクリックすると配下すべてを一括で展開・折りたたみ）。サイドバー右上のフォルダアイコンは「表示するフォルダを選び直す」ボタンで、新規フォルダの作成はできません。矢印キーでツリー内を移動し、`Return` キーで選択中のPDFを開けます。サイドバーと本文の境界をドラッグすると幅を変更できます。

サイドバーヘッダーには4つのボタンがあります。「Aa/時計」アイコンは並べ替えの基準（名前順・更新日順）を、矢印アイコンはその向き（昇順・降順）をそれぞれワンクリックで切り替えます。カレンダーアイコンは各項目の更新日の表示・非表示を単独で切り替え、表示時はファイル名の方が省略されて更新日は常に見えるようになります。回転矢印アイコンは表示中のフォルダを読み直します——アプリの外でPDFを増やしたり消したりしても一覧は自動では追いつかないため、そのための入口です（フォルダ未選択のときと読み込み中は押せません）。フォルダは並べ替え条件によらず常に先頭にまとまります。

シークバーは本文の下端にマウスカーソルを近づけると現れ、離れると消えます。右綴じでは右端が1ページ目で、読み進むほどつまみが左へ動きます。つまみをゆっくり動かすとページが追従し、一気に振ったときは指を離した位置へ飛びます。

サイドバーでは1クリックがPDFの選択、ダブルクリックが「開く」に対応しており、`Command` クリック・`Shift` クリックで選択を複数のPDFへ広げられます。選択したPDFを右クリックすると「最初に戻る」（保存された読書位置を先頭に戻す）と「ゴミ箱に入れる」が選べます。この2つの操作はツールバーの対応するボタンからも行え、その場合はサイドバーで選択中のPDFが対象になります（何も選択していなければ、開いているPDFが対象になります）。削除はmacOSのゴミ箱へ移動するので、Finderから元に戻せます。フォルダは削除の対象になりません。

最終ページで「次へ」を押すと次の巻が開き、逆に1ページ目で「前へ」を押すと手前の巻の最終ページが開きます。誤って隣の巻へ移ってしまっても、同じ操作でそのまま引き返せます。ツールバーの二重矢印のボタンを使えば、ページ位置に関わらずいつでも隣の巻へ移れます（並び順は綴じ方向に合わせて反転し、隣に巻が無いときは押せません）。こちらは明示的な操作なので、自動で移る設定をオフにしていても使えます。

端まで読んだときに自動で隣の巻へ移る動作が不要なら、ツールバーの本が並んだアイコン、または「表示」メニューの「最終ページで次の巻へ自動的に進む」をオフにしてください（設定はアプリ全体で記憶されます）。

サイドバーの検索欄にキーワードを入力すると、ファイル名またはフォルダ名が部分一致するPDFだけに絞り込まれます（大文字・小文字は区別しません）。検索中はフォルダの階層を畳んで、一致したPDFを直接一覧に並べるので、深い階層にあるPDFもフォルダを開かずにそのまま選べます。フォルダ名が一致した場合は、その配下のPDFがすべて対象になります。ルート直下以外のPDFには、どのフォルダの本かが分かるように親フォルダ名が添えられます。一致がなければ「PDFが見つかりません」と表示されます。フォルダを切り替えると検索語は消えます。

## 開発者向け

Swiftのテストとインストール処理のシェルテストは、リポジトリのルートで次を実行します。

```sh
swift test
zsh Tests/InstallAppScriptTests/install-app-bundle-tests.sh
```

Releaseビルドのアプリバンドルを生成するには、次を実行します。

```sh
scripts/build-app.sh
```

生成先は `build/PDFComicViewer.app` です。Finderでダブルクリックするか、次のコマンドで開きます。

```sh
open build/PDFComicViewer.app
```
