# PDF漫画ビューアー

PDF漫画をmacOSで1ページ表示・見開き表示して読むためのネイティブビューアーです。

## 主な特徴

- 右綴じ・左綴じ
- 1ページ・見開き表示の即時切り替え
- 横長ページの自動単独表示
- PDFごとのページ位置・表示設定の保存
- キーボード、クリック、ドラッグによる操作

## 必要環境

- macOS 15.0以降
- Swift 6.0以降（インストール・更新・ソースからのテスト・ビルドに必要）

## インストール

リポジトリのルートで次を実行します。このコマンドはReleaseビルドを行ってからアプリを配置します。

```sh
scripts/install-app.sh
```

`~/Applications/PDF漫画ビューアー.app` にインストールされ、自動的に起動します。

このアプリは未署名・未公証の個人利用向けローカルビルドです。ほかのMacへの配布には、別途コード署名と公証が必要です。

## 更新

ソースを更新した後、インストール時と同じコマンドを実行します。

```sh
scripts/install-app.sh
```

## 基本操作

- PDFを開く: ツールバーの「PDFを開く」、ファイルのドラッグ＆ドロップ、または `Command + O`
- 次へ進む: `Space`。矢印キーと画面左右のクリック領域は綴じ方向に応じて反転
- 前へ戻る: `Shift + Space`
- 1ページ表示: `1`
- 見開き表示: `2`
- 見開き位置を1ページずらす: `S`
- 拡大: `Command + +`
- 縮小: `Command + -`
- ウインドウに合わせる: `Command + 0`
- 全画面表示の切り替え: `Control + Command + F`

綴じ方向、表示方法、見開き位置、拡大・縮小、全画面表示はツールバーからも操作できます。見開き表示中にページ上で右クリックすると、そのページを「自動」「単独」「見開き」のいずれで扱うか指定できます。

## 開発者向け

Swiftのテストとインストール処理のシェルテストは、リポジトリのルートで次を実行します。

```sh
swift test
zsh Tests/InstallAppScriptTests/install-app-bundle-tests.sh
```

Releaseビルドのアプリバンドルを生成するには、次を実行します。

```sh
scripts/build-app.sh
```

生成先は `build/PDFComicViewer.app` です。Finderでダブルクリックするか、次のコマンドで開きます。

```sh
open build/PDFComicViewer.app
```
